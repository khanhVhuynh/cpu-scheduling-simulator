# CPU Scheduling Simulator

A CPU scheduling project developed in C as part of my Computer Systems Programming coursework at George Mason University.

## Project Overview

This project focuses on implementing task scheduling operations using linked lists, bitwise operations, and low-level C programming techniques.

## Key Features

- Task management and scheduling operations
- Linked-list-based data structures
- Bitwise operations for task information
- Testing and debugging of scheduling functionality

## Technologies

- C
- Linux
- Git and GitHub

## Skills Demonstrated

- Systems programming
- Data structures
- Memory management concepts
- Debugging and problem-solving
